# ADR-0003 · V1 仅原生 PDF 路径；扫描件后置但架构预留

- 状态：已接受（2026-08-21）
- 决策层级：难逆（决定 V1 全部工作量分布与 writer 选型）

## 背景

调研报告推荐扫描件路径优先（绕开 Tier 1 成本、差异化）。设计会话中决策者选择相反方向：V1 目标与 BabelDOC 对标，先做原生 PDF 的解析翻译；扫描件需要 OCR，后续版本再做，但架构设计必须预留。

## 决策

1. V1 只处理原生 PDF；检测到扫描件时明确报错拒绝（行为与 BabelDOC 一致）。
2. 写回模型：增量改写（保留原 PDF 全部对象，只改 content stream、追加字体）。
3. 架构预留：IR 的文本载体设计为可扩展的和类型，为 V2 的 OCR 行级文本（无字体/字号/图形状态）预留变体；从零重建 writer（扫描件路径必需）留接口不实现。
4. PP-OCRv6 移出 V1 资产清单（V1 无 OCR）。

## 后果

- V1 直面调研报告标注的 Tier 1 成本：段落/公式启发式调参 + 畸形 PDF 长尾。缓解手段是从第一个里程碑就建立语料回归网（Corpus v1 + 快照测试），语料需求与生成合同见 `docs/03-corpus-requirements.md`。
- content stream 解释/走查、增量写回、字体子集化全部进入 V1 范围。
- 输入语言与 OCR 解耦：V1 输入语言基本无关（取决于 PDF 文本提取），验收只对英→中负责。
